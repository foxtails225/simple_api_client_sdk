# Hunter SDK

Hunter SDK is a lightweight Python client for interacting with the [Hunter.io API](https://hunter.io/api-documentation). It allows you to:

- ✅ Validate email addresses
- ✅ Find emails associated with a domain
- ✅ Generate professional emails from a name and company
- ✅ Cache API responses using in-memory storage

---

## Installation

### **1️⃣ Clone the Repository**

```sh
git clone https://github.com/foxtails225/simple_api_client_sdk.git
cd hunter_sdk
```

### **2️⃣ Create a Virtual Environment**

```
python -m venv venv
venv\Scripts\activate # On Windows
```

### **3️⃣ Install Dependencies**

```
pip install -r requirements.txt
```

### \*\* Add .env file

```
HUNTER_API_KEY=your_api_key
```
